# On-Page SEO Checklist

Apply every rule while writing. Use the scorecard at the end for the pre-publish check.

## Keyword placement

| Location | Rule |
|---|---|
| Meta title | Focus keyword included, ideally in the first half; 50–60 characters |
| Meta description | Keyword included once; 140–155 characters; ends with a benefit or CTA |
| URL slug | Lowercase, hyphenated, 3–5 words, keyword included, no stop words or dates |
| H1 | Contains the keyword; only one H1 per page |
| First 100 words | Keyword appears once, naturally |
| H2/H3 | Keyword or close variant in at least 2 subheadings |
| Body | ~0.8–1.5% density; mix exact match, variants, synonyms |
| Conclusion | Keyword or variant appears once |
| Image alt text | At least one alt text includes the keyword; all alt text is descriptive |

Never force the exact keyword into a sentence where it reads unnaturally — use a variant.

## Semantic coverage

- Cover the entities, sub-topics, and terms that most top-ranking pages mention.
- Answer the "next question" a reader would have after each section.
- Add one section or angle that competitors miss (the content gap).

## Structure and readability

- Paragraphs: 2–4 sentences. Sentences: most under 20 words.
- Use a subheading every 200–300 words.
- Use bullet or numbered lists for steps, features, and pros/cons.
- Include at least one table when comparing options, specs, or prices.
- Bold key takeaways sparingly (1–2 per section at most).
- Active voice in at least 90% of sentences; use transition words.
- Target Flesch reading ease 60+ (grade 8–9) unless the audience is technical.

## Featured snippet targeting

- Question-style keyword → add a 40–60 word direct answer right after the intro, starting
  with the answer, not a restatement.
- "How to" keyword → numbered steps, each starting with a verb.
- "Best / vs / types of" keyword → a list or table near the top.

## E-E-A-T and trust

- Use specific numbers, dates, and named sources; link to the source.
- Include practical examples, mistakes to avoid, or expert tips that show experience.
- Never fabricate statistics, studies, quotes, reviews, or credentials.
- Flag anything time-sensitive (prices, laws, versions) with the year checked.
- For health, finance, or legal topics (YMYL), add a brief "consult a professional" note
  and cite authoritative sources (government, academic, official bodies).

## Links

**Internal (3–5):** Descriptive anchor text (2–5 words, varied, never "click here").
Format when the site URL is unknown: `[anchor text](/suggested-slug)` and list them in the
link suggestions table as "Internal — page idea".

**External (2–4):** Authoritative, non-competing sources (government, academic, standards
bodies, original research, official docs). Link the source of each statistic. Only use
URLs actually found during research — never invent a URL.

## Images

Suggest 2–4 placements in the form:
`[Image: short description — alt="descriptive alt text with keyword where natural"]`
Suggest a descriptive filename (e.g. `running-shoe-cushioning-comparison.webp`).

## Things to avoid

- Keyword stuffing, doorway phrasing, or repeating the same sentence pattern.
- Filler intros ("In today's fast-paced world…") and generic conclusions.
- Claims without evidence; outdated information.
- Duplicate or near-duplicate headings.
- Walls of text over 5 lines on desktop.

## Pre-publish scorecard

Mark each item ✅ or ⚠️ (with a one-line fix). Report the score as X/20.

1. Meta title 50–60 chars, keyword included
2. Meta description 140–155 chars, keyword + CTA
3. URL slug short, keyword included
4. Single H1 with keyword
5. Keyword in first 100 words
6. Keyword/variant in ≥2 subheadings
7. Keyword density ~0.8–1.5%, no stuffing
8. Semantic terms and entities covered
9. Content gap addressed
10. Word count within ±10% of target
11. Subheading every 200–300 words
12. Short paragraphs, readable sentences
13. At least one list and one table (where relevant)
14. Featured-snippet block present (if applicable)
15. 3–5 internal link suggestions
16. 2–4 authoritative external links
17. Image suggestions with alt text
18. FAQ section with 6–8 query-style questions
19. FAQPage JSON-LD valid and matching visible text
20. All statistics sourced; no fabricated data
